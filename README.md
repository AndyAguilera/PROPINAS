# Propinas · Beraza y Cia SRL (Playa)

Sistema de control de propinas en un único archivo (`index.html`), sin servidor ni base de datos.

- Los datos se guardan en el navegador de cada PC (y opcionalmente en una carpeta elegida en Ajustes).
- Para pasar los datos a otra PC o navegador: **Ajustes › Exportar copia** y después **Ajustes › Restaurar copia**.
- Para actualizar la versión publicada: reemplazar `index.html` en este repositorio. Vercel vuelve a publicar solo.

Usar con Google Chrome o Microsoft Edge.
